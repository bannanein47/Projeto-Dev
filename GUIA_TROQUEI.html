01 · Visão geral

O que é o Troquei?

O Troquei é um projeto de site para facilitar a troca de objetos entre pessoas. A ideia é dar um novo uso ao que alguém já não precisa: cada usuário cria sua conta, anuncia seus itens e procura algo que tenha interesse em receber.

A descoberta funciona por interesse mútuo. Uma pessoa marca que gostou do item de outra; quando a outra também gosta de um item dela, o sistema registra uma combinação. A partir daí, as duas podem conversar para acertar a troca e, depois, marcá-la como concluída.

O objetivo do grupo é construir esse caminho funcionando de verdade, com páginas, regras e dados salvos. Como é um trabalho acadêmico, o site será executado no próprio computador, com Flask e SQLite, sem necessidade de contratar hospedagem ou serviços pagos.

O trabalho será dividido em entregas semanais, acompanhadas pelo docente. Na apresentação de 7 de outubro, o foco é demonstrar contas, categorias e gerenciamento de itens. Até o fim de novembro, o grupo deverá apresentar o fluxo completo e conseguir explicar como cada parte foi feita.

Planejamento, Trello e regras — Matheus
  1. Desenhe o começo e o fim. Exemplo: visitante preenche cadastro → sistema valida → conta é criada ou aparece um erro.
  2. Transforme cada etapa em regra. Use frases como “se… então…” e inclua os casos que devem ser recusados.
  3. Quebre em cartões pequenos. Cada cartão deve caber em até dois encontros e ter responsável, teste e evidência.
  4. Revise com quem programará. Confirme se entrada, resultado e erro estão claros antes de começar o código.

09 · Regra central

Quando existe uma combinação?

A combinação acontece entre dois itens específicos, não apenas entre duas pessoas.

Ana gosta do item de BrunoO sistema salva a decisão, desde que Ana não tenha avaliado o item antes.
+
Bruno gosta de um item disponível de AnaA segunda decisão cria a reciprocidade.
=
Combinação ativaOs dois participantes podem abrir a conversa.

Sempre verificar

  • é item de outra pessoa;
  • usuário ainda não avaliou;
  • os dois itens estão disponíveis;
  • existe interesse recíproco;
  • o mesmo par ainda não possui combinação.

Ao concluir a troca

  • combinação recebe estado concluido;
  • os dois itens recebem estado trocado;
  • itens deixam de aparecer na vitrine;
  • histórico continua disponível para os participantes.
